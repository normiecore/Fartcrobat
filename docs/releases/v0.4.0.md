## Fartcrobat is now Inkmoor

Same app, new name. Copies of Fartcrobat 0.2 or 0.3 update to Inkmoor like any other update, and keep what you set up:

- **Settings, recent files, Digital IDs and AI app connections carry over.** Inkmoor keeps using the folder Fartcrobat stored them in.
- **Windows:** the update replaces Fartcrobat in place, in the same folder. This one update downloads the whole installer (about 120 MB) instead of only the changed parts. The Fartcrobat shortcuts are replaced by Inkmoor ones on the desktop and in the Start menu; if you pinned Fartcrobat to the taskbar, pin Inkmoor again. If you made Fartcrobat the default PDF app in Inkmoor's Preferences or the installer, Inkmoor is; if you picked Fartcrobat.exe under "Open with", choose Inkmoor there once more (Preferences offers Make default).
- **Mac:** download Inkmoor below, drag it to Applications, then move Fartcrobat to the Bin.
- **Ubuntu and Debian:** `sudo apt install ./inkmoor_0.4.0_amd64.deb` upgrades the installed Fartcrobat package (it keeps its package name, `fartcrobat`). The app moves to `/opt/Inkmoor` and the command is now `inkmoor`; scripts that ran `fartcrobat` need the new name.
- **AppImage:** the update replaces the file in place, so it keeps its old file name until you rename it.
- **Remembered passwords** on Mac and Linux may have to be typed once more: the system keychain stores them under the app's name.
- **Claude Desktop and ChatGPT Desktop:** open Inkmoor once after the update before asking an AI app to use it; after that, the installed Claude extension and ChatGPT setup keep working. (On Windows after Later, and on Ubuntu and Debian, the old extension cannot start the app by itself until then.) Add the Claude extension again from **Preferences → AI apps → Add to Claude Desktop** to see the new name.

### For administrators

Machine policies move to `HKLM\SOFTWARE\Policies\Inkmoor` on Windows, `/etc/inkmoor/policy.json` on Linux and `/Library/Application Support/Inkmoor/policy.json` on Mac. Policies at the old Fartcrobat locations still apply; where both set the same setting, the new location wins.

Windows installers remain unsigned; macOS builds are ad-hoc signed.

## What's new

- **Tabs can move between windows.** Drag a tab out of the tab strip to open it in a window of its own, or onto another Inkmoor window's tabs to move it there; drag it along the strip to reorder. Right-click a tab, or use **Window → Move to New Window** and **Move to Another Window…**, to do the same without dragging. Unsaved changes, the page and zoom, and the password or certificate the document was opened with come along; undo history stays behind, and Inkmoor says so.
- **New Window** has a shortcut: Ctrl+Alt+N (Cmd+Option+N on a Mac).
- **Files opened from other apps** can open in a new window: **Preferences → General → Open files from other apps in**. A file that is already open is shown where it is instead of opening twice.
- AI apps keep working with a document after its tab moved to another window.

## Security fixes

This release fixes security issues found in a review of 0.3.0. Update soon, especially if you open PDF or HTML files from other people or rely on digital signatures. Details will follow in a security advisory.

- **Opening HTML files:** web pages are converted without running their scripts and can only use files from their own folder.
- **Digital signatures:** a signature now shows a warning when the document was changed after signing, unless the change is another signature. Use **View signed version** in the Signatures panel or Signature Properties to see exactly what was signed. Filling in a form after someone signed it now shows this warning too. Certificates and timestamps are checked more strictly.
- **Remove Hidden Information, then sign:** the removed information no longer comes back in the signed file.
- **Links and attachments:** Inkmoor asks before touching files on other computers, and files saved from attachments are marked as downloaded, so Windows and macOS warn before opening them. More risky file types are blocked from opening directly.
- **Form scripts in PDFs** can no longer freeze the window or open dialogs, links or print on their own.
- **Office files** are converted without loading linked content from the internet.
