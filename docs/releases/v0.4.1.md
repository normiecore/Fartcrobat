## Inkmoor has its own address

The project moved to **github.com/normiecore/Inkmoor**, and 0.4.1 looks for updates there. Earlier copies (Fartcrobat 0.1 to 0.3 and Inkmoor 0.4.0) look at the old address and won't find 0.4.1 or anything after it. Install 0.4.1 by hand once; from then on it updates itself as before.

- **Windows:** run the installer below. It replaces Fartcrobat or Inkmoor 0.4.0 in the same folder and keeps your settings. Uninstalling the old copy first works too.
- **Mac:** drag Inkmoor to Applications, then move Fartcrobat to the Bin if you have it.
- **Ubuntu and Debian:** `sudo apt install ./inkmoor_0.4.1_amd64.deb` upgrades the installed Fartcrobat or Inkmoor package.
- **AppImage:** download the new file and delete the old one.

Settings, recent files, Digital IDs and AI app connections carry over.

**Coming from Fartcrobat (0.1 to 0.3)?** This is also the switch to the new name, so the notes for [0.4.0](https://github.com/normiecore/Inkmoor/releases/tag/v0.4.0) apply, in short:

- Remembered passwords on Mac and Linux may have to be typed once more.
- Open Inkmoor once before asking Claude Desktop or ChatGPT Desktop to use it.
- Windows: pin Inkmoor to the taskbar again if you had Fartcrobat there, and if you chose Fartcrobat under "Open with", choose Inkmoor (Preferences offers Make default).
- Ubuntu and Debian: the app is now in `/opt/Inkmoor` and the command is `inkmoor`.

The 0.4.0 notes also list everything new since 0.3 (tabs between windows, Organize Pages zoom, the security fixes).

## Also in 0.4.1

- **Organize Pages:** at two pages per row, some window widths showed a horizontal scrollbar. They don't any more.
- Help > Inkmoor on GitHub, and the Windows installer's wrong-processor message, link to the new address.
