## What’s new

- **Companion connection without an invitation:** click Chat here in Fartcrobat, then use Fartcrobat from a Claude or ChatGPT conversation. Its next successful call connects that conversation to the in-app chat; there is nothing to copy and paste. Nothing connects before you open the chat.
- **On-document edit review:** proposed text edits appear on the document with highlights and a Review edits side panel. Accept or reject individual edits, accept all, or discard the batch. Rejected edits disappear from the preview; accepted choices are applied together with one Undo step.
- **Gentle working animation:** three companion poses indicate real tool activity, pause during review, and respect reduced-motion settings.
- **Conversation isolation:** another chat—even in the same desktop connection—cannot obtain the active chat token or consume its messages. End & clear, or closing that conversation's app, ends the chat until you choose Allow a new conversation.
- **One download per computer:** each release now lists one file for each kind of computer (Windows, Windows on Arm, Mac with Apple silicon or Intel, Ubuntu and Debian, other Linux) in the table above. The Windows installer for both processors is gone; the Windows on Arm installer stops on other PCs and names the right file.
- **No request to Google on Linux:** 0.2.0 on Linux asked Google's download server for a spell-check dictionary each time it started. 0.2.1 makes no request of its own besides the update check, on every system.

## After updating

Reinstall the bundled Claude Desktop extension from **Preferences → AI apps**, then restart Claude Desktop so it loads the updated tool instructions and companion responses. Restart ChatGPT Desktop if you use its local MCP connection.

The companion still uses your active external AI conversation. It cannot wake a finished or closed chat; the UI distinguishes connection from listening.

Proposals arrive as the agent submits tool calls, not as model-token streaming. Ask for small batches to review edits progressively. Linked multi-page reflow and full rebuilds are reviewed as one layout change to keep columns and pagination consistent. New continuation pages appear in the review panel before approval.

Windows installers remain unsigned; macOS builds are ad-hoc signed.
