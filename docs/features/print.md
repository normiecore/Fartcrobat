# Feature: print

Printing, Acrobat style.

- Command file.print (Mod+P, File menu group 'print', toolbar icon via docToolbar is fine) opens a Print dialog closely modelled on Acrobat's: Printer dropdown (invoke('print:printers'); default selected) with 'Properties' (opens system dialog: print:images with silent false), Copies, 'Print in grayscale', 'Save ink/toner' optional; Pages to print: All / Current page / Pages (ranges like '1-3, 5, 8-' and page labels) / More options: odd or even pages, reverse pages; Page Sizing & Handling: Size (Fit, Actual size, Shrink oversized pages, Custom scale %), Multiple (pages per sheet 2/4/6/9/16, page order horizontal/vertical, print page border), Booklet (binding left/right, sheets from-to); Orientation: Auto portrait/landscape, Portrait, Landscape; Comments & Forms: Document and Markups (default), Document, Document and Stamps, Form fields only; a live preview on the right with page navigation (render the composed sheet exactly as it will print) and the sheet size (Letter/A4/Legal/A3/Tabloid, default from locale) and the 'Page x of y' preview counter; Print button.
- Rendering: compose each output sheet on an OffscreenCanvas/canvas at 300 DPI (150 DPI option 'Print as image draft') from page images (doc.core.render.image, with annots/widgets per the Comments & Forms choice; 'Document' => no annotations, 'Form fields only' => only widgets... implement as faithfully as MuPDF render options allow), apply sizing/rotation/N-up/booklet imposition, encode PNG/JPEG and call invoke('print:images', job) with silent:true and the chosen printer (or silent:false if the user chose system dialog). Show progress (withProgress) for large jobs; cancel button.
- Respect permissions: if !info.permissions.print show an explanation instead of the dialog.
- Remember last settings (store:set 'print:settings').
- Engine: none needed beyond core render.image unless you need it (namespace 'print').
- Pure functions for page-range parsing and imposition (N-up / booklet ordering / fit scaling) must have unit tests (tests/engine/print.test.ts can import from src/features/print).
e2e: open text.pdf, Mod+P opens dialog, choose 'Pages 2-3', 2 pages per sheet; preview shows 1 sheet with 2 pages (screenshot); printing in tests must not hit a real printer: in the test, stub window.api.invoke for 'print:images' via page.evaluate to capture the job, then assert sheet count/size.
