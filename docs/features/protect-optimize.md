# Feature: protect-optimize

Acrobat 'Protect a PDF' (tool group 'protect') and 'Compress a PDF' / 'Optimize PDF' (tool group 'compress').

- Protect panel: 'Protect using password' (command protect.encrypt): dialog with 'Require a password to open the document' (password + confirm, strength meter), 'Restrict editing and printing' (permissions password + Printing allowed: None/Low resolution/High resolution; Changes allowed: None / Inserting, deleting and rotating pages / Filling in form fields and signing / Commenting, filling in form fields and signing / Any except extracting pages; Enable copying of text, images and other content; Enable text access for screen readers), Encryption level (AES-256 default; AES-128, RC4-128 compatibility), passwords cannot contain commas (MuPDF limitation — validate). Map choices to core SaveOptions.encrypt permissions bits (print, print-hq, edit, annotate, form, assemble, copy, accessibility). Applying: the document is marked so the next Save writes encrypted (store pending SaveOptions per document and wrap the save: the cleanest is to immediately 'Save As' a protected copy with saveDocument(doc, {saveAs:true, saveOptions}) after explaining it); show a success message with what is restricted.
- 'Remove security' (command protect.removeSecurity): if the doc is encrypted: if opened with owner rights just confirm; if permissions restricted, ask for the permissions/owner password (verify by reopening the bytes in a temporary EngineClient and authenticate: MuPDF authenticatePassword returns 2/4 for user/owner) then save with decrypt.
- Show current security in the panel (info.encryption, permissions) and a lock badge in the doc toolbar (docToolbar item) for encrypted docs that opens the panel. Respect restrictions in the UI: if !permissions.edit / annotate / form / assemble / copy, show a document message bar 'This document has restricted permissions' (do not try to disable other features — just inform; copying text when copy is not allowed should be blocked: register a higher-priority command? No — simply show a toast; edit-text etc are other features).
- Compress (tool group 'compress', command compress.open, Home tile): one-click 'Compress' with a quality choice (High quality / Medium (default) / Small size) and an 'Advanced optimization' dialog (Acrobat's PDF Optimizer): Images: downsample colour/grayscale images above X ppi to Y ppi (bicubic), JPEG quality; monochrome images; Fonts: subset embedded fonts (doc.subsetFonts()), Discard: metadata, thumbnails, form actions/JS, bookmarks, comments, flatten form fields; Clean up: compress uncompressed streams, remove unused objects and duplicates (SaveOptions garbage 'deduplicate', compressFonts/Images, clean). Engine namespace 'protect-optimize': image downsampling op (iterate image XObjects of all pages (dedupe by object number), compute effective ppi from the largest drawn size (use stext image blocks transforms or a device that records fillImage ctm), decode with s.pdf.loadImage(ref).toPixmap(), resample to target size (e.g. with DrawDevice drawing the image into a smaller Pixmap or Pixmap.warp), re-encode JPEG (pixmap.asJPEG(quality)) for colour/gray without alpha (keep PNG/Flate for images with SMask or few colours), replace the XObject stream with addRawStream/ writeRawStream and correct /Filter /DCTDecode /Width /Height /BitsPerComponent /ColorSpace /DecodeParms removed), report before/after sizes. Then the result opens as a new tab or saves as '<name>_compressed.pdf' with a summary 'Reduced from 12.4 MB to 3.1 MB (75% smaller)'.
- Unit tests: encrypt with open password + no-copy, reopen requires password and reports permissions; remove security; compress a fixture with a large image (create tests/fixtures/protect-optimize/big-image.pdf: a 3000×3000 photo-like image placed at 2 in) -> output smaller, image downsampled to ~150 ppi, text intact, opens fine.
e2e: open text.pdf, Protect using password (open password 'abc'), save via stubbed dialog, reopen file -> password prompt appears (screenshot), enter 'abc'; compress the big-image fixture and see the size message.
