# Feature: markup-tools

All comment creation tools (Acrobat 'Add comments' tool group, id 'comment', and the comment quick tools).

- Tool group 'comment' panel (ToolPanelFrame titled 'Add comments'): sections Text markup (Highlight, Underline, Strikethrough, Squiggly, Insert text, Replace text), Comments (Add sticky note, Add text comment/typewriter, Text box, Callout), Drawing (Draw free form, Eraser, Rectangle, Oval, Line, Arrow, Polygon, Connected lines, Cloud, Highlight area), Stamps & measure (rows for tools stamps.stamp, measure.distance, measure.perimeter, measure.area — only if registered), and at the bottom the comment commands if registered (comments.export, comments.import, comments.summarize, comments.toggleVisibility). Each row shows its shortcut.
- Contextual toolbar (tool.toolbar) for every tool: colour, fill (shapes), opacity, line width, line style (solid/dashed/cloudy where applicable), arrow ends (line/arrow), font size and font colour (text tools), and a 'Keep tool selected' pin (prefs.keepToolSelected). Remember defaults per tool in store ('markup-tools:defaults'); also honour 'comments:defaults:<type>' if present.
- Tools (ids in contracts), all creating annotations via core annots.create with author set by the engine:
  * comment.note (S): click places a Text note (icon Comment, colour yellow) and dispatches 'fartcrobat:edit-annotation'.
  * comment.highlight (U), comment.underline, comment.strikeout, comment.squiggly: drag across text to select it (use doc.pageText + caretAt/rangeQuads like the core text layer; show live selection highlight), on release create the markup with one quad per line. If text was already selected when the tool is chosen, apply immediately to the selection. Also register textSelectionActions: Highlight (order 10), Underline (20), Strikethrough (30), Add note to text (40: highlight + open popup).
  * comment.insertText: click between characters -> Caret annotation at that point + popup for the inserted text. comment.replaceText: select text -> StrikeOut + Caret (grouped via inReplyTo/IRT 'Group' semantics if feasible, otherwise linked by extra).
  * comment.typewriter: click -> FreeText (intent FreeTextTypeWriter, no border) and inline editing ('fartcrobat:edit-annotation'); comment.textbox (X): drag a box -> FreeText with border; comment.callout: click point then drag box -> FreeText intent FreeTextCallout with callout line.
  * comment.pencil (D): free-hand Ink with smoothing (simplify points, e.g. Ramer–Douglas–Peucker), multiple strokes go into the same annotation until you pause 1.5s or switch tools; pressure not needed. comment.eraser: drag over Ink annotations to erase the parts of strokes it touches (split strokes; delete the annotation if empty) via annots.update.
  * Shapes: comment.rectangle, comment.oval (Shift = square/circle), comment.line, comment.arrow (Shift snaps to 45°), comment.polygon, comment.polyline (click points, double-click/Enter to finish, Esc cancels, show rubber band), comment.cloud (polygon with cloudy border), comment.areaHighlight (drag rectangle -> Highlight with a rectangular quad, multiply blend, for scanned pages).
  * Live previews while drawing (SVG in the tool layer, in page space via geometry).
  * After creating: unless keepToolSelected, switch back to 'select' and select the new annotation (doc.setSelection kind 'annotations').
- quickTools: comment.note (10), comment.highlight (20), comment.pencil (30). Menu 'comment' with all tools grouped (Text markup / Comment / Drawing), single-key shortcuts: S note, U highlight, Shift+U cycle markup? (optional), D pencil, X text box.
- Engine: use core annots ops; add namespace 'markup-tools' only if you need extra ops (e.g. stroke splitting can be done in the UI).
e2e: open text.pdf; choose Highlight from the quick toolbar, drag across 'quick brown fox' on page 1 -> one Highlight with quads covering those words (check via annots.list); select text with the select tool then click 'Underline' in the selection mini toolbar; draw a rectangle and an arrow with Shift; draw with the pencil; place a sticky note; erase half an ink stroke; undo/redo each.
