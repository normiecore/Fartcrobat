# Feature: stamps-measure

Stamps (Acrobat 'Add a stamp' tool group, id 'stamp') and Measuring tools (Acrobat Pro 'Measure objects', id 'measure').

STAMPS
- Tool stamps.stamp (shortcut K): a stamp palette in the tool group panel and in the tool's contextual toolbar dropdown: Standard Business (Approved, Not Approved, Draft, Final, Completed, Confidential, For Public Release, Not For Public Release, For Comment, Void, Preliminary Results, Information Only, Experimental, Expired, Sold, Top Secret, Departmental) — use MuPDF's built-in stamp appearances by setting the Stamp icon name where MuPDF supports it, otherwise draw the stamp yourself (rounded border, bold text, colour) to a PNG with a canvas in the UI and pass it as stampImage; Sign Here (Sign Here, Witness, Initial Here, Accepted, Rejected); Dynamic (Approved, Reviewed, Received, Revised, Confidential) that include the author name (authorName()) and date/time, rendered to PNG at create time with a canvas. Custom stamps: 'Create custom stamp' from an image file (PNG/JPEG) or from a PDF page (render it via a temporary EngineClient), named and stored in store ('stamps-measure:custom') as PNG data URLs; manage (rename/delete) in the panel. Each palette item shows a preview image.
- Placing: click places at a default size (keeping aspect ratio), drag to size; the last-used stamp is remembered; stamps are Stamp annotations (selectable/movable via the comments feature). Subject = stamp name.
MEASURE
- Tools measure.distance, measure.perimeter, measure.area in tool group 'measure' (panel with the three tools, the scale ratio setting, units, precision, snap-to-endpoints toggle, and a list of measurements on the page).
- Scale: '1 in = 1 ft' style (page units in/cm/mm/pt × real units in/ft/yd/mi/mm/cm/m/km), default from prefs.measurementUnits; stored per document via a custom /FartcrobatMeasure dictionary in the document catalog (engine op) and in each measurement's extra.
- Distance: click-click (Shift snaps 45°) -> Line annotation with intent LineDimension, line endings both 'Butt'/'OpenArrow', caption text with the measured value (contents = '3.25 ft', show caption via setLineCaption if possible, else draw the label yourself in a FreeText-free way: contents + MuPDF caption), extra {fartcrobat:'measure', kind:'distance', value, unit, scale}. Perimeter: polyline (PolyLine with intent PolyLineDimension) click points, double-click to finish; Area: polygon (Polygon intent PolygonDimension) with area in square units. Live readout near the cursor while measuring and in the panel ('Measurement info': distance, angle, delta X/Y).
- Snap to page content endpoints optional (snap to text-line corners is fine).
- Engine namespace 'stamps-measure': helper ops (read/write the doc measurement scale, set line caption). Unit-test geometry maths (distance/perimeter/area incl. scale conversion) and the engine ops.
e2e: open text.pdf; place 'Approved' stamp by click and a dynamic stamp by drag (check annotations); create a custom stamp from tests/fixtures/scan.png (stub the open dialog via page.evaluate overriding window.api.invoke for 'file:openDialog'); measure a distance between two points 144pt apart with scale 1 in = 1 ft -> '2 ft'; measure an area.
