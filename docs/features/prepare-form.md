# Feature: prepare-form

Acrobat 'Prepare a form' (tool group 'prepareform') and 'Request e-signatures' (tool group 'requestsign').

- Engine namespace 'prepare-form': create fields of every type by building widget annotation + field dictionaries with low-level objects (Subtype Widget, FT Tx/Btn/Ch/Sig, Ff flags, T name, TU tooltip, DA '/Helv 0 Tf 0 g', Q, MaxLen, Opt arrays, MK with BC/BG/CA (check style ZapfDingbats characters: check 4, circle l, cross 8, diamond u, square n, star H), AP normal appearances for checkbox/radio On/Off states, Parent/Kids for radio groups with shared /V), register in /AcroForm /Fields (create AcroForm with /DA and /DR including /Helv and /ZaDb fonts if missing, set NeedAppearances false and generate appearances with widget.update()), add to the page /Annots, and reload the page so MuPDF sees the widget. Also: update field properties, rename (unique names, Acrobat-style auto names 'Text1', 'Check Box2'...), move/resize (rect), duplicate (to other pages too), delete (remove from Annots, AcroForm Fields and parent Kids), set tab order (/Tabs and order of /Annots), set format/keystroke/validate/calculate JavaScript actions (AA with JS strings using the AF* functions — same subset forms-fill emulates: AFNumber_Format/Keystroke, AFPercent, AFDate_FormatEx, AFSpecial_Format, AFRange_Validate, AFSimple_Calculate) and the /CO calculation order. All mutations undoable. Thorough unit tests incl. round trip save/reopen and that core forms.listAll sees the created fields with correct types/options/flags.
- Auto-detect fields ('Prepare a form' on a document without fields asks 'Detect form fields automatically?'): heuristics on doc.pageText and vector/line hints: runs of underscores or long horizontal rules following a label -> text field named from the label ('Name', 'Date' -> date format), small squares (☐, □, [ ]) -> checkboxes, 'Signature'/'Sign here' labels with a line -> signature fields, table-like grids -> text fields per cell is optional. Test on a fixture with lines and labels you create (tests/fixtures/prepare-form/blank-form.pdf).
- UI: when the group is open, tool 'form.select' (the form editing select tool) is active: every field shows as a blue box with its name; click selects (custom selection type 'prepare-form:fields'), Shift-click multi-select, rubber-band select, drag to move, handles to resize, arrow keys nudge, Delete deletes (command form.delete ['Delete','Backspace'], enabled only for this selection), Mod+D duplicates? (optional), right-click menu (Properties, Duplicate, Delete, Align left/right/top/bottom, Center horizontally/vertically, Distribute, Match width/height/both, Set tab order). Creation tools: form.text, form.checkbox, form.radio (adding radios to an existing group by name), form.list, form.dropdown, form.button, form.signature, form.date — click to place default size or drag to size; after creation an inline name box appears (Acrobat style) with 'Required field' and 'All properties' link.
- Properties dialog: General (name, tooltip, visible/hidden/print, read only, required, orientation), Appearance (border colour, fill colour, line thickness, font (Helvetica, Times, Courier, Zapf), font size incl. Auto, text colour), Options per type (alignment, default value, multi-line, scroll long text, password, check spelling, limit characters, comb of N characters; checkbox style and export value, checked by default; list items add/remove/reorder/export values, sort, allow user to enter custom text, multiple selection, commit immediately), Actions (button: Reset form, Open a web link, Go to page — store as standard PDF actions), Format (None/Number/Percentage/Date/Time/Special with options), Validate (range), Calculate (sum/product/average/min/max of picked fields, or simple notation 'a + b * c' converted to an event.value script).
- Right panel 'fields' (order 50): list of fields by page with type icons in tab order, rename inline, click selects/scrolls; drag to reorder tab order. 'Preview' button toggles back to normal filling (setTool('select')).
- 'Request e-signatures' group 'requestsign': since this app is offline, explain plainly and offer the practical workflow: add signer signature fields (form.signature, assign signer names to fields as tooltips), then 'Save and share' which saves the PDF and opens the user's mail client with a mailto: link (subject/body; attaching is up to the user — show the file path with 'Show in folder'). No fake cloud UI.
