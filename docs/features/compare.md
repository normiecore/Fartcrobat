# Feature: compare

Acrobat 'Compare files' (tool group 'compare', Home tile).

- Panel: choose Old file and New file (from open tabs, recent files, or Browse…), options: compare text only / text and images, ignore whitespace/case, page range; 'Compare' button. Works with or without an open document (requiresDocument false; when opened from a document, it is preselected as 'Old').
- Engine: open each file in its own EngineClient (new EngineClient(); doc.open) — or use the open DocumentModels' engines — extract per-page text with word positions (core text.page), align pages (page count may differ; match pages by text similarity), run a word-level diff (package 'diff' installed: diffWordsWithSpace / diffArrays on tokens) across the whole document text with page/position mapping, classify changes: inserted, deleted, replaced (adjacent delete+insert), formatting-only (same text, different font/size/colour — optional), page added/removed/moved; also visual differences for images/graphics when 'text and images' is chosen (render both pages at low DPI, pixel diff ignoring text areas, cluster changed regions into rectangles).
- Results view via toolGroups[].documentView: side-by-side Old | New page views (render pages with doc.core.render through each engine; your own simple synchronized scrolling viewer is fine — reuse PageGeometry for coordinates) with change highlights (red = deleted on old side, green = inserted on new side, orange/blue = replaced/changed images), synchronized scrolling and zoom, a 'Single page overlay' toggle (new page drawn over old with difference blend), a results summary panel on the left (counts by type, list of changes with snippets: 'Replaced “$1,234.56” with “$9,876.54”' on page 1; click scrolls both sides to it; filter by type), next/previous change buttons, and 'Export report' that creates a PDF report (new tab via openNewDocument): a summary page plus annotated copies of the new document's changed pages (use core annots on a copy: highlight inserted text, strikeout deleted text positions with popup notes) — Acrobat produces a similar report.
- Cancel/progress for large documents; no blocking of the UI thread for big diffs (chunk the work, or run the diff in a small dedicated Web Worker).
- Unit tests for the diff/alignment logic on synthetic page texts and on compare-a.pdf vs compare-b.pdf (expects exactly 2 changes: '$1,234.56' -> '$9,876.54' and 'finance' -> 'audit').
e2e: compare compare-a.pdf with compare-b.pdf (stub file:openDialog), results view shows 2 changes with highlights on both sides (screenshot, look at it), clicking a change scrolls; export report opens a new tab.

## Protected documents

The compare report shows text from both documents, so when either is password-protected or restricted the report keeps the protection of the first protected one (Old, then New), with the same method, permissions and passwords (see the organize-pages notes and `src/engine/util/protection.ts`). The report is built in the New document's engine; the protecting document's engine then applies its security (`compare.protectReport`), the report tab opens with that document's password without asking again (`compare.openPassword`), and the result message says whose protection it kept. When the protected document was a tab that has since been closed, the report cannot be created until the files are compared again.
