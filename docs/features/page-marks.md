# Feature: page-marks

Headers & footers, watermarks, backgrounds, Bates numbering and cropping pages (Acrobat 'Edit a PDF' > More / Document menu).

- All marks are real page content: for each target page append a separate content stream (wrapped in q/Q, drawn on top for headers/footers/watermarks-on-top/Bates, or PREPENDED for backgrounds and watermarks 'behind page') whose stream dictionary carries /FartcrobatMark /HeaderFooter | /Watermark | /Background | /Bates and a JSON copy of the settings (/FartcrobatSettings (string)) so marks can be detected, updated and removed later; also wrap the operators in /Artifact marked content (BDC/EMC) with /Subtype /Header|/Footer|/Watermark|/Background like Acrobat. Fonts: base-14 via addSimpleFont (Helvetica, Times-Roman, Courier and bold/italic variants), images via addImage with an ExtGState for opacity. Respect page /Rotate (marks appear upright relative to the viewed page) and the CropBox.
- Header & Footer (commands marks.headerFooter.add/update/remove; menu Document > Header & Footer ▸): dialog with six text boxes (left/centre/right × header/footer), font/size/colour/underline, margins (in the user's units), insert page number (formats '1', '1 of n', 'Page 1', 'Page 1 of n'), insert date (several formats), start page number, page range (all / from-to, odd/even), 'Shrink document to avoid overwriting' optional, live preview of the page with the marks (render the current page then draw the header/footer preview on a canvas overlay), save/load presets (store 'page-marks:presets').
- Watermark (marks.watermark.add/update/remove): text (font, size or 'scale relative to page', colour) or image/PDF page file source, rotation (0/45/-45/custom), opacity, position (vertical/horizontal alignment + offsets), scale, appearance options 'show when printing/displaying', on top/behind, page range, live preview.
- Background (marks.background.add/update/remove): colour or image/file (scale, opacity, rotation, position), page range, preview.
- Bates numbering (marks.bates.add/remove): prefix, suffix, number of digits, start number, position (one of the 6 header/footer slots), font, page range; one document at a time.
- Crop pages (command marks.crop activates tool marks.crop): drag a rectangle on a page, then a 'Set Page Boxes' style dialog: margins top/bottom/left/right (units), 'Remove white margins' (compute the content bounding box: render the page at low DPI and find non-white pixel bounds), 'Set to zero', apply to all/range/odd/even pages, page boxes (Crop/Trim/Bleed/Art) with core pages.setBox; remove crop (reset to MediaBox).
- Update/remove: detect existing marks per type (engine op listing marks with their settings); 'Update' opens the dialog prefilled; 'Remove' deletes those streams on all pages (asks to confirm). Engine namespace 'page-marks', all mutations undoable (one undo step per dialog OK).
- Tool group 'pagemarks' panel listing these commands with short descriptions (edit-text's Edit panel also lists them).
- Unit tests: add header/footer with 'Page <<1>> of <<n>>' and check page text on each page (doc text contains 'Page 3 of 5'), update changes it, remove restores the original text exactly; watermark text appears in the page text and remove removes it; background behind content (the original text still extracts first/unchanged); Bates numbers; crop sets CropBox and 'remove white margins' finds the content bounds; rotated page (mixed-sizes.pdf page 3) header is upright (text extraction direction).
e2e: open text.pdf, add a footer 'Page 1 of n' + a diagonal 'CONFIDENTIAL' watermark at 30% opacity via the dialogs, screenshot and look at it; remove the watermark; crop page 1 by dragging; undo.
