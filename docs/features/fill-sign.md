# Feature: fill-sign

Acrobat 'Fill & Sign' (tool group 'fillsign') for forms that are not interactive, and personal signatures/initials.

- Panel (ToolPanelFrame 'Fill & Sign'): big 'Sign yourself' button (signature and initials), tool rows for Add text (fillsign.text), Cross mark, Check mark, Dot, Line, Rounded box (fillsign.cross/check/dot/line/box), Date (fillsign.date), plus 'Request e-signatures' row that opens tool group 'requestsign' if registered, and a short tip. Quick tool fillsign.text (order 40) and command fillsign.signYourself (order 50, icon PenLine) in the quick toolbar.
- fillsign.text: click anywhere to add a text field: creates a FreeText annotation (no border, transparent, Helvetica, default size 12, colour black, extra {fartcrobat:'fillsign'}) and immediately starts inline editing in place (do your own inline editor for fillsign items: an absolutely positioned contenteditable/textarea matching the zoom; on commit annots.update contents and resize the rect to fit the text). Comb-like 'letter spacing' option optional. A floating mini toolbar above the active text item: smaller/larger font (A- A+), delete, and a dropdown to convert it to another mark — like Acrobat's Fill & Sign.
- Symbols: check/cross/dot/line/box create small Ink/Square/Circle annotations sized relative to the font size, extra {fartcrobat:'fillsign'}; date inserts today's date text (locale format, editable).
- Signatures: 'Sign yourself' menu shows saved signature and initials (previews) + 'Add signature' / 'Add initials' / 'Clear saved'. Create dialog with tabs Type (name -> choose among 4 handwriting fonts from @fontsource/dancing-script, great-vibes, caveat, allura — import their CSS/woff2 in your feature; render with canvas), Draw (smooth pen strokes on a canvas, clear, colour black/blue), Image (PNG/JPEG file, auto-crop whitespace, make white transparent), and 'Save signature' checkbox. Stored as transparent PNG data URLs in store ('fill-sign:signature', 'fill-sign:initials'). Choosing one activates fillsign.place: the signature follows the cursor as a ghost; click places a Stamp annotation (stampImage PNG, extra {fartcrobat:'fillsign', kind:'signature'}) at a natural size (signature height ≈ 0.5 in, keep aspect ratio); Esc cancels.
- Your own pageLayer (order 45) gives fillsign items direct manipulation even without the comments feature: drag to move, corner handle to resize (keeping aspect for signatures), double-click text to edit, Delete removes (command fillsign.delete with ['Delete','Backspace'] enabled only for a custom selection {kind:'custom', type:'fill-sign:item'}). Do not interfere with other comments.
- Settings section 'Signatures' in Preferences: manage saved signature/initials (view, replace, delete), default text size.
- Engine namespace 'fill-sign' only if needed.
e2e: open text.pdf; add text at a point, type 'Jane Doe', commit; add a check mark; create a typed signature 'Jane Doe' (choose a font), place it; move it by drag; reopen the Sign menu shows the saved signature; screenshots; save (stubbed dialog) and reopen in a fresh window: annotations present.
