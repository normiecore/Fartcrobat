# Feature: redact

Acrobat 'Redact a PDF' (tool group 'redact') — permanent removal of sensitive content.

- Tool redact.mark ('Redact text & images'): drag across text to mark text (quads, like text markup) or drag a rectangle anywhere for an area (images/graphics); double-click a word marks it; marks are Redact annotations (core annots.create type 'Redact' with quads/rect, overlay properties) shown with a red outline (MuPDF draws them) and listed in the panel; selectable/deletable via the comments feature too. 'Mark page range' (redact whole pages: rect = page bounds) dialog.
- Find text & redact (command redact.findText): panel/dialog with Single word or phrase / Multiple words or phrases (list) / Patterns (Phone numbers (US + international), Email addresses, Credit card numbers (with Luhn check), Social security numbers, Dates); options whole words/match case; search all pages (doc.pageText + searchPage with regex) and show results with context and checkboxes ('Check all'), 'Mark checked results for redaction'.
- Redaction properties (settings section 'Redaction' + panel): fill colour (default black), overlay text (custom text or 'redaction code' e.g. '(b)(6)'), font/size/colour, auto-size text, repeat overlay text, outline colour shown before applying.
- Apply (command redact.apply; button in panel and a document message bar 'n redaction marks — Apply'): confirm dialog explaining permanence ('Redaction marks will be applied permanently and cannot be undone after you save'), with 'Also remove hidden information' checked by default; engine op (namespace 'redact', one mutation) calls page.applyRedactions(black_boxes=true, image method REDACT_IMAGE_PIXELS (removes only covered pixels), line art REMOVE_IF_COVERED, text REMOVE) for each page with marks, then draws the overlay text into each redacted area (content stream with base-14 font, centred/repeated per settings) — verify the underlying text is gone from text extraction and from the saved file bytes (search the saved PDF bytes and decompressed streams for the secret string).
- 'Remove hidden information' / 'Sanitize document' (command redact.sanitize, also offered after applying): checklist dialog — metadata (Info dict and XMP /Metadata), file attachments, bookmarks, comments and markups (annotations), form fields (flatten or remove), hidden text (Tr 3 invisible text — optional), hidden layers (OCG off), embedded search index, JavaScript actions (names tree /JavaScript, /OpenAction JS, AA), links to external pages, overlapping objects (optional); results report what was removed. Engine ops do the removal (low-level object edits) and save with sanitize/clean options at save time (use core saveDocument options: SaveOptions.sanitize, garbage 'deduplicate' — expose a flag so the next File > Save uses them, or run 'Save As' right away).
- Panel (ToolPanelFrame 'Redact a PDF'): Redact text & images, Find text & redact, Mark page range, Properties, list of marks by page (click to go, delete), Apply, Sanitize.
- Unit tests: mark 'SSN: 123-45-6780' on text.pdf page 1, apply, text gone from extraction and from saved bytes (inflate streams with zlib in Node to check), the rest of the line remains, an image area redaction removes pixels (render and check colour), patterns find all 5 SSNs/emails/phones in text.pdf, sanitize removes metadata/attachments/JS/annotations.
e2e: open text.pdf, Find text & redact with pattern 'Email addresses' -> 5 results -> mark all -> apply (confirm) -> search 'billing' finds nothing; screenshot.
