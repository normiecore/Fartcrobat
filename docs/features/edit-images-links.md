# Feature: edit-images-links

Editing images and links inside 'Edit a PDF' (the panel is owned by edit-text; you provide tools/layers it lists).

- Images inside 'Edit text & images' mode: pageLayer 'edit-images' (order 60, when toolId === 'edit.content') with a hit box for every image on visible pages (doc.pageText(page).images gives bbox + transform; you may add an engine op listing image XObjects with their transform and xref for precise identification, including inline images). Click selects (custom selection 'edit-images-links:image'), shows handles: drag to move, corner handles resize (keep aspect with Shift... Acrobat keeps aspect by default on corners), a rotate handle or commands Rotate 90° clockwise/counterclockwise, Flip horizontal/vertical, Replace image… (file), Extract/Save image as… (PNG), Delete (command edit.deleteImage ['Delete','Backspace'] enabled only for this selection), Arrange (bring forward/backward), Crop image (optional). Right-click menu with the same.
- Engine namespace 'edit-images-links' (all mutations undoable): implement image transform changes precisely: find the content stream operator 'cm' + 'Do' (or inline image BI/ID/EI) that paints that image instance, and change its matrix (simplest robust approach: remove the image draw via MuPDF redaction with image method REMOVE restricted to the image bbox and line-art/text NONE, then append a new content stream drawing the same XObject (reuse the existing /XObject reference, do not duplicate image data) with the new matrix, wrapped in q/Q; or rewrite the operators directly in the content stream if you can parse it reliably). Replace = add new image (doc.addImage(new Image(bytes))) at the same matrix and remove the old drawing. Delete = remove drawing. Extract = image bytes (Image.toPixmap().asPNG()).
- edit.addImage tool: pick an image file, then click to place at natural size (72 dpi → points, scaled to fit the page) or drag a rectangle; written as page content (XObject + content stream).
- Links: tool edit.link ('Add/Edit Web or Document Link'): shows all existing link rectangles with outlines; drag to create a new link -> dialog: Link action 'Go to a page view' (page number + current zoom/position by navigating and 'Set link') or 'Open a web page' (URL) or 'Open a file' (path → launch action, optional), appearance (visible rectangle/invisible, highlight style none/invert/outline, line colour/style/thickness); select existing link to move/resize/edit properties/delete (Delete key command edit.deleteLink enabled only for selection 'edit-images-links:link'). Engine: page.createLink(bbox, uri) / deleteLink / link.setBounds / setURI; for internal destinations use a '#page=N&zoom=...' URI form MuPDF understands or build /Dest arrays with low-level objects (verify with core nav.links that dest.page resolves). Also 'Create links from URLs' command (edit.autoLinks): scan page text for http(s)://, www., emails and create link annotations (Acrobat Pro feature).
- Unit tests for every engine op (move/resize/delete/replace image keeps other content; add image; links create/edit/delete/auto-detect; round trip). Fixture: tests/fixtures/edit-images-links/images.pdf with 2 images and text (make it with reportlab).
